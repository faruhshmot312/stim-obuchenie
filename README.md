# Стим — обучение операторов (Telegram Mini App)

Каталог товаров со скриптами звонка, характеристиками, возражениями и проверкой для операторов колл-центра.

- `index.html`, `app.js` — сайт (открывается в Telegram как Mini App и в обычном браузере).
- `products.json` — все товары. Поле `photo` — путь к фото в `photos/`.
- `photos/<id>.webp` — главное фото товара.
- `SYNC.md` — как обновлять товары из Google Таблицы.
