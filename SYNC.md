# Обновление из Google Таблицы

Источник: Google Таблица «Товары — информация», id `1lFtfBwRtknZvhv4nCOjcuxjFSVwGO008V6jB8MjoRIU`, лист «Товары», колонки:
A — Склад (TRUE/FALSE), B — Наименование товара, C — ссылка на PDF в Google Drive, D — ссылка на сайт товара.

Правила сверки с `products.json`:
1. Товар находится по ссылке на сайт (без https://, www. и завершающего /), иначе по названию (без учёта регистра и ё/е).
2. Найден — обновить `stock`, `row`, `pdf`, `video`; `name` менять только если название в таблице отличается не только регистром. Если был `hidden: true` — убрать.
3. Не найден — новый товар. `id` = `p` + номер строки двумя цифрами (`p41`); если занят — `p41_2`.
   - Прочитать PDF (Google Drive, read_file_content по id из ссылки `/d/<id>/`).
   - Перенести дословно в формат остальных товаров: `subtitle, cat (auto|home|repair|health|kids), price, old` (цифры с пробелами, «169 000»), `script` [[шаг, реплика]], `important`, `table_title`, `table` (первая строка — заголовки), `notes`, `side_title`, `side`, `objections` [[«возражение», «ответ»]]. Ничего не придумывать; убрать колонтитулы «Интернет-магазин Стим · … · N» и обратные слеши.
   - Фото: открыть сайт товара, взять первую картинку `<img>` с непустым `alt` (часто это `data:` base64 — декодировать), проверить, что это сам товар и она чёткая; если нет — выбрать лучшее фото товара на странице. Сохранить в `photos/<id>.webp` (конвертировать в webp), записать `"photo": "photos/<id>.webp"`.
   - Если PDF нет или не читается — не добавлять товар, сообщить в отчёте.
4. Товары, которых больше нет в таблице, — `hidden: true` (не удалять). Ничего не делать, если в таблице меньше 3 товаров.
5. Порядок в `products.json` — по `row`. Проверить, что JSON валиден и у каждого видимого товара есть файл фото.
6. Коммит в `main` только если что-то изменилось: «Синхронизация с таблицей: +N новых, M изменено».

Не трогать при синхронизации: `config.js` (адрес серверной части), папку `apps-script/`.
